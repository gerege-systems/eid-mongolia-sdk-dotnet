# RP SDK цөм: «eID-ээр нэвтрэх» товчны backend + ASP.NET Core adapter (нийтлэгдээгүй)

- **Юу:** `GeregeSystems.EidMongolia.Login` — framework-аас хамааралгүй `EidLoginHandler` (Go `eidlogin.Handler`, TS
  `createEidLogin` / `handleRequest`-ийн порт): `POST start` (qr | push), `GET start?mode=web2app` (302), `GET status`
  (PENDING + шинэ QR | WAIT_CALLBACK | OK | FAILED | EXPIRED), `GET callback` (Web2App, verifier, 303); HttpOnly + Secure +
  SameSite=Lax cookie binding (`<sessionId>.<binding>`, SHA-256-ийг тогтмол хугацаанд тулгана); `IEidLoginStore` +
  `MemoryEidLoginStore` (TTL, 10 000 дээд хэмжээ, дүүрвэл 503 `busy`); хязгаар (`EidLoginRateRule`, start 20/мин IP,
  push 3/мин дугаар, нэмэлт hook); `EidLoginClientIp.RemoteAddress` / `Forwarded(n)` (итгэмжит proxy илэрхий); decoy push
  ба push floor (1 с); TTL-ийг discovery `sessionTtl.auth` / CA `expiresAt`-аар таслах; ValidateAuth + OCSP
  (`OcspRevocationChecker`, soft-fail анхдагч) дараа нэг удаа `OnSuccess`; `OnEvent` аудит (HMAC pushKey); 12 алдааны
  код Go/TS-тэй ижил HTTP статустай. Шинэ project `GeregeSystems.EidMongolia.AspNetCore` (FrameworkReference л):
  `services.AddEidMongolia(...)`, `app.MapEidLogin("/auth/eid", ...)`, `EidLoginHttp`. Хоёр project хоёулаа pack хийгдэхгүй.
- **Go/TS-ээс ялгаа:** `OnEvent`-ийн алдааг залгиж Log руу (TS); OnSuccess нь `EidLoginSuccess.Headers`-ээр (TS) эсвэл
  ASP.NET-д HttpContext-оор cookie тавина; `data` нь camelCase JSON; JSON бие хатуу задлагдана (Go-д мөрийн дараах хог
  зөвшөөрөгддөг); failure redirect-ийн query дараалал хадгалагдана (Go эрэмбэлдэг).
- **Хаана:** `src/GeregeSystems.EidMongolia/Login/*.cs`, `src/GeregeSystems.EidMongolia.AspNetCore/`, тест
  `tests/GeregeSystems.EidMongolia.Tests/Login/*.cs`, `tests/GeregeSystems.EidMongolia.AspNetCore.Tests/`; README.
- **Хэрхэн шалгасан:** PR CI (Windows + Linux, net8.0 + net10.0): `eidlogin/scenarios.json`-ийн 24 сценари бүгд
  (start/status/callback JSON, cookie, decoy, rate-limit түлхүүр, аудит), conformance PKI-ийн бодит гинж + ACSP_V2 гарын
  үсэг + OCSP replay-тэй OK зам (QR, Web2App), Go `security_test.go` / `eidlogin_test.go`-ийн аюулгүйн кейсүүд
  (удирддаг цагтай push floor, replay, binding/fixation, cross-site, цуцлалт, store), Kestrel loopback дээр adapter.
