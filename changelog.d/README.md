# changelog.d — нэг өөрчлөлт, нэг файл

`CHANGELOG.md`-г feature салбар/PR дотор засахгүй (CI-ийн `changelog` job шалгана; зөвхөн `release/*` салбар засна).
Өөрчлөлт бүр `changelog.d/<YYYY-MM-DD>-<сэдэв>.md` файлд: юу · яагаад · хаана · хэрхэн шалгасан. Release хийхдээ
фрагментуудыг `CHANGELOG.md`-ийн шинэ хувилбарын хэсэгт оруулаад файлуудыг устгана (README «Release»).
